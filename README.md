# 🌱 Agrofloresta: Produzir e Conservar é Possível?

Plataforma educacional interativa sobre sistemas agroflorestais, desenvolvida para conscientizar sobre práticas sustentáveis que unem produção agrícola, conservação ambiental e biodiversidade. 

## 🚀 Funcionalidades

- 📖 Conteúdo educativo sobre agroflorestas
- 🖼️ Galeria de imagens ilustrativas
- 🎯 Quiz interativo
- 📊 Indicadores e informações resumidas
- 🗂️ Sistema de abas temáticas
- 🎞️ Carrossel de exemplos e casos reais
- 🎥 Conteúdo multimídia integrado
- ❓ FAQ interativo
- ♿ Recursos de acessibilidade (aumento de fonte e alto contraste)
- 📱 Layout responsivo para dispositivos móveis

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📚 Temas Abordados

- Sustentabilidade rural
- Conservação do solo e da água
- Biodiversidade
- Sistemas agroflorestais
- Educação ambiental
- Agricultura sustentável

## ▶️ Como Executar

1. Baixe os arquivos do projeto.
2. Mantenha `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra o arquivo `index.html` em seu navegador.
